**A Mod Manager for our fellow survivors!**

TLD Mod Manager is a small tool with a companion mod and plugin that help modding of The Long Dark for new or long time players.

The plugin ensures mod that the mods are up to date and possibly in the future allows for other little things, like automatic mod downloading if connection to another player over Sky CO-OP is established.

The mod meanwhile embeds itself with ModSettings and allows you to Save, Create and Export modpacks. 

**WARNING!**

The mod manager itself is and will forever be provided as-is, so please make backups of your already installed mods and most importantly ModData folder inside `/TheLongDark/Mods/` as that contains data thats not saved to the actual save files.

**Contribution**
